# Portal-AI-Desktop
Portal AI Desktop یک نرم‌افزار دسکتاپ یکپارچه برای استفاده از هوش مصنوعی ابری و محلی است. این برنامه ابزارهای چت، کدنویسی، مدیریت و اجرای مدل‌های Local AI، تولید و پردازش تصویر و رسانه، مدیریت Runtimeها و امکانات توسعه را در یک محیط واحد ارائه می‌دهد. هدف آن ساده‌کردن دسترسی به مدل‌های مختلف AI بدون نیاز به ابزارهای متعدد و پیچیده است.
