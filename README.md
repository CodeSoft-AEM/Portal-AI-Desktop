# پورتال هوش مصنوعی دسکتاپ

Portal AI Desktop

یک نرم‌افزار دسکتاپ یکپارچه برای استفاده از هوش مصنوعی ابری و محلی است.

این برنامه ابزارهای چت، کدنویسی، مدیریت و اجرای مدل‌های هوش مصنوعی محلی، تولید و پردازش تصویر، ابزارهای رسانه‌ای و مدیریت موتورهای اجرایی را در یک محیط واحد در اختیار شما قرار می‌دهد.

هدف برنامه این است که استفاده از مدل‌های مختلف هوش مصنوعی را ساده‌تر کند و نیاز به نصب و مدیریت چندین نرم‌افزار جداگانه را کاهش دهد.

> نسخه فعلی در مرحله آزمایشی قرار دارد و ممکن است بعضی قابلیت‌ها هنوز در حال توسعه باشند.

## مرحله اول: دانلود موتور اجرایی

ابتدا وارد بخش هوش مصنوعی محلی شوید.

Local AI

سپس بخش مدیریت موتورهای اجرایی را باز کنید.

Runtime Center

در این بخش می‌توانید موتورهای اجرایی موردنیاز را مشاهده، دانلود و مدیریت کنید.

مراحل کلی:

1. موتور اجرایی مناسب را انتخاب کنید.
2. گزینه دانلود یا نصب را بزنید.
3. منتظر بمانید دانلود کامل شود.
4. پس از آماده شدن، وضعیت آن را در همان بخش بررسی کنید.

موتورهای اجرایی حجیم همراه فایل اصلی برنامه قرار داده نشده‌اند تا حجم دانلود اولیه برنامه بیش از حد زیاد نشود.

## مرحله سوم: اجرای مدل

بعد از دانلود مدل و موتور اجرایی:

1. مدل موردنظر را انتخاب کنید.

3. منتظر بمانید وضعیت آماده نمایش داده شود.
4. وارد بخش چت یا ابزار مرتبط شوید.
5. استفاده از مدل را شروع کنید.

در بسیاری از بخش‌ها برنامه تلاش می‌کند مدیریت موتورهای اجرایی را تا حد ممکن به‌صورت خودکار انجام دهد.
